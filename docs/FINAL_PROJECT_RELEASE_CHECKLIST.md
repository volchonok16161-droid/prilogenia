## Границы безопасности

- Не изменять `main`, Production Render и Production Supabase.
- Preview сейчас использует тот же Supabase project, что и Production. До тестов, способных изменять Auth, таблицы, Storage или пользователей, проверить безопасный тестовый сценарий.
- Не применять миграции к Production и не деплоить Edge Functions в Production в рамках сборки.
- Не удалять существующие записи, фото, LocalStorage/IndexedDB или очереди синхронизации ради теста.
- Не включать Render auto-deploy и не выпускать Production без отдельного согласования.
