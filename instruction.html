Чек-лист ТМХ/НЭВЗ: установка и работа

Приложение для проверки локомотивов при ТР-50, ТР-250, ТР-500. Работает на телефоне, планшете и компьютере. Приложение и эта инструкция отправляются вам в мессенджере eXpress.

Установка на iPhone и iPad (Safari)

  1. Откройте ссылку на приложение в Safari. Если ссылка пришла в eXpress, откройте её не внутри мессенджера, а в Safari: нажмите на ссылку и выберите открытие в браузере либо скопируйте ссылку и вставьте её в адресную строку Safari.
  2. Нажмите кнопку Поделиться (квадрат со стрелкой вверх). На iPhone она внизу экрана, на iPad — вверху.
  3. Прокрутите список действий и выберите На экран «Домой».
  4. Оставьте название «Чек-лист» и нажмите Добавить.
  5. Иконка появится на главном экране. Дальше запускайте приложение с неё, а не из Safari.
Первый запуск — только с интернетом. Приложение загружает всё необходимое и запоминает это, после чего может работать без сети.

На iPhone и iPad приложение устанавливается только по ссылке. Файл для установки, как APK на Android, на iPhone не подходит.

Установка на Android

Вариант 1. Файл APK (если вам прислали файл)

  1. Скачайте файл с расширением .apk из чата eXpress: нажмите на файл и выберите «Скачать» или «Сохранить».
  2. Откройте скачанный файл: из уведомления о загрузке или в приложении «Файлы» → «Загрузки».
  3. Если Android пишет, что установка из этого источника запрещена, нажмите «Настройки» и разрешите установку приложений для программы, из которой открываете файл (eXpress или «Файлы»). Затем вернитесь назад.
  4. Нажмите Установить. Если система защиты (Play Protect) покажет предупреждение, выберите «Всё равно установить».
  5. Нажмите Открыть или найдите иконку «Чек-лист» на главном экране.
Названия пунктов зависят от модели телефона и версии Android. После установки файл APK можно удалить. Чтобы обновить приложение, установите новый APK поверх старого, а перед этим сделайте «Экспорт JSON».

Вариант 2. По ссылке

  1. Откройте ссылку на приложение в Chrome. Если ссылка пришла в eXpress, скопируйте её и вставьте в адресную строку Chrome.
  2. Нажмите меню ⋮ справа вверху и выберите Установить приложение (в некоторых версиях — «Добавить на главный экран»).
  3. Подтвердите установку. Иконка «Чек-лист» появится на главном экране.

При первом запуске подключитесь к интернету: приложение загрузит всё необходимое, после чего сможет работать без сети.

Как пользоваться

Вход и выбор чек-листа

  1. На экране «Авторизация» введите любой логин и пароль (например, свою фамилию и любой пароль) и нажмите Войти.
  2. Выберите чек-лист из списка:
    • Комплексный чек-лист (ТР-50, ТР-250, ТР-500)
    • Чек-лист проверки КМБ, колёсно-моторный блок (ТО-2)
    • Чек-лист проверки ТТ, тяговый трансформатор (ТР-50)
    • Чек-лист проверки БИ, МСУД-015 (ТО-2)
    • Чек-лист проверки гидродемпферов (ТР-50)
  3. Другой чек-лист можно открыть в любой момент кнопкой 🔄 Сменить чек-лист. Данные каждого чек-листа сохраняются отдельно, при переключении ничего не теряется.

Если вы уже начинали заполнение, приложение спросит: Продолжить заполнять или Начать новый (очистить всё). Второй вариант стирает введённые данные.

Заполнение

  1. Сначала выберите тип электровоза, иначе приложение не даст продолжить. Затем укажите номер, дату осмотра, место осмотра и пробег.
  2. Пройдите по разделам и отметьте результат каждой проверки. Если приложение показывает «Требуется прикрепить фото», добавьте фото. В сообщении указано, сколько ещё осталось.
  3. Приложение не позволит отметить «Да» сразу для всех подпунктов в группе — проверьте, всё ли верно выбрано.
  4. Чтобы быстро найти пропущенное, нажмите 🔍 Найти незаполненное. Число рядом — сколько полей осталось.

Кнопки внизу экрана

🔍 Показать позиции, требующие уведомления
Показывает позиции с замечаниями, по которым нужно уведомить поставщика. Число рядом — их количество.
💾 Сохранить в браузере
Данные сохраняются автоматически при каждом изменении. Кнопка подтверждает сохранение.
💾 Сохранить как файл
Сохраняет копию чек-листа с введёнными данными в отдельный файл.
📷 Экспорт Excel
Формирует итоговый файл Excel. Работает, только когда чек-лист заполнен на 100%. Внутри четыре листа: «Данные», «Фотографии», «Сводная» и «История изменений».
📤 Экспорт JSON и 📥 Загрузить JSON
Резервная копия данных. Экспортируйте JSON, если хотите продолжить на другом устройстве или защититься от потери данных. Загрузка возвращает всё, что было в файле.
✕ Очистить всё
Удаляет все данные без возможности восстановления. Перед этим сделайте Экспорт JSON.

Вверху экрана переключается тема «Светлая» / «Тёмная», а кнопка «Выход» завершает сеанс.

Как выгрузить готовый результат

  1. Заполните все поля, пока счётчик у кнопки «Найти незаполненное» не станет 0.
  2. Нажмите 📷 Экспорт Excel. Появится сообщение «Экспорт выполнен успешно».
  3. Найдите файл: на iPhone — в приложении «Файлы» в папке «Загрузки», на Android — в «Файлы» → «Загрузки». Оттуда его можно отправить кнопкой «Поделиться».

Частые вопросы

Кнопка «Экспорт Excel» выдаёт «только при 100% заполнении»

Нажмите «Найти незаполненное» и заполните оставшиеся поля и обязательные фото. Когда всё заполнено, появится сообщение «Все данные и операции заполнены».

Пропали введённые данные

Данные хранятся в памяти браузера на этом устройстве. Они могут исчезнуть, если очистить историю и данные сайтов, удалить приложение или открыть приложение в другом браузере. На iPhone установите приложение на экран «Домой»: в обычной вкладке Safari данные сайтов, которыми давно не пользовались, могут быть удалены. Чтобы не потерять работу, делайте Экспорт JSON.

Как перенести данные на другой телефон

На старом устройстве нажмите «Экспорт JSON», отправьте файл себе, а на новом откройте приложение и нажмите «Загрузить JSON».

Работает ли приложение без интернета

Да, после первого запуска с интернетом. Первый раз откройте приложение при включённой сети, чтобы оно загрузило всё необходимое, в том числе для выгрузки в Excel.

После обновления приложение выглядит по-старому

Закройте приложение полностью и откройте снова при включённом интернете. Если не помогло, закройте и откройте ещё раз.

Excel-файл не открывается или не находится

Проверьте папку «Загрузки». Для открытия нужно приложение для таблиц: Excel, Numbers, Google Таблицы.
