## Выявленные незавершённые пункты

1. История миграций активного проекта содержит только `20261102110411_profiles_self_update_display_name`, хотя таблицы, политики и триггеры уже существуют. Источник базовой схемы/её происхождение в migration history не зафиксированы. Не запускать повторное создание схемы вслепую; сначала сверить полный фактический DDL и подготовить baseline.
2. Основное приложение пока не подключено к завершённому end-to-end потоку Auth + облачные чек-листы. Текущий `account.html` — кабинет, но не доказательство полной миграции старой авторизации и локального состояния.
3. Для приглашений `account-admin` пока не задаёт `redirectTo`. Нужен подтверждённый основной origin и разрешённый Redirect URL в Supabase Auth. Не использовать recovery-домен как callback приглашения.
4. Лимит 15 сотрудников проверяется обычным чтением перед приглашением и не атомарен при параллельных запросах. До production нужен транзакционный серверный лимитер/счётчик.
5. Supabase Security Advisor сообщает, что Leaked Password Protection выключена. Настройка не менялась; её включение требует отдельной оценки доступности/плана и тестирования пользовательских сценариев.
6. Не выполнены реальные тесты писем, принятия приглашения, восстановления пароля и отрицательные A/B проверки доступа к строкам с двумя независимыми Auth-пользователями.
